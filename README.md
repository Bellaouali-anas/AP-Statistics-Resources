# 📊 AP Statistics — Interactive Teaching Resources

An evolving collection of **AP Statistics teaching and learning resources** developed throughout the **2026–2027 academic year**.

This repository contains materials I create and use while teaching AP Statistics, with an emphasis on combining **statistical reasoning, real-world data, and modern technology**.

The materials are organized according to the AP Statistics course framework and will continue to be updated as we progress through the course.

---

## 🎯 About This Project

The goal of this project is to create clear, practical, and interactive resources that can support both **AP Statistics teachers and students**.

Rather than focusing only on formulas and calculations, the materials encourage students to:

- Explore real datasets
- Visualize distributions and relationships
- Interpret statistical results in context
- Use technology to investigate statistical concepts
- Develop statistical reasoning and communication skills
- Connect mathematical concepts with real-world applications

Python and interactive notebooks are incorporated where they can help students better understand the ideas behind the statistics.

## 🐍 Statistics with Python

One of the objectives of this project is to introduce students to how statistics can be explored using modern computational tools.

Python notebooks may use libraries such as:

- **Pandas** — data manipulation and exploration
- **NumPy** — numerical calculations
- **Matplotlib** — statistical visualization

The notebooks are designed to **complement statistical reasoning**, not replace it.

Students can use the notebooks to interact with data, modify parameters, create visualizations, and observe how statistical results change.

The `.ipynb` files can be opened with **Jupyter Notebook** or uploaded directly to **Google Colab**.
